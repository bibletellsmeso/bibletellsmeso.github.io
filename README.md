# Andrew Shin

Source for [bibletellsmeso.github.io](https://bibletellsmeso.github.io/), a small static site for power-systems research and selected open-source work.

The published page is plain HTML and CSS. GitHub Pages serves it directly; no theme, site generator, or local build step is required.

## Update the page

- Edit `index.html` for content.
- Edit `assets/css/portfolio.css` for presentation.
- Preview by opening `index.html` locally, then commit and push the change to `master`.
