# Andrew Shin — Research Portfolio

Source repository for [bibletellsmeso.github.io](https://bibletellsmeso.github.io), Andrew Shin's research portfolio on power-system optimization, robust decision-making, and real-time simulation.

## What is here

- `index.md` — the portfolio landing page and selected-software links
- `_config.yml` — site identity, author metadata, and GitHub Pages configuration
- `_data/navigation.yml` — the top navigation
- `assets/css/main.scss` — portfolio-specific visual styling
- `_posts/` — research notes and dated posts

The site is built with the Minimal Mistakes Jekyll theme. Its source files remain in this repository because GitHub Pages uses them during publication.

## Preview locally

Install Ruby and Bundler, then run:

```powershell
bundle install
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000` in a browser. The deployed branch is `master`; portfolio changes should be reviewed in a pull request before merging.

## Content policy

This public site links only to material intended for release. Ongoing manuscripts, raw research records, literature collections, and sensitive project material remain in the private research repositories until they are ready to publish.
